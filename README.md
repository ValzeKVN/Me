# Me

My personal link-in-bio page — a single-page site with quick links to my resume, work, and socials.

**Live:** https://valzekvn.github.io/Me/

## What's here

- `index.html` — the page (self-contained: HTML, CSS, and a little JS, no build step)
- `Kevin-Valenzuela-Resume.pdf` — my current resume, linked from the page
- `profile.jpg` — avatar image (falls back to initials if missing)

## Links on the page

- View My Resume
- AIT — Data Analyst
- LinkedIn
- Instagram
- TikTok

## Running locally

Just open `index.html` in a browser — no dependencies, no build step.

## Deployment

Hosted with GitHub Pages, served from the repo root on the `main` branch.
